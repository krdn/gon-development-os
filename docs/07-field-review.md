## 모델 운영 정책

자동 후보는 Astra/Fable이다. simple+low는 low, 일반 작업은 medium, complex 또는 high 영향도는 high, frontier 또는 critical은 xhigh를 사용한다. 높은 위험 기준부터 적용한다. 모델만 명시해도 같은 위험도 표를 적용하며, 명시 effort나 정확한 배포 ID가 있으면 그 값을 우선한다. 지원 범위로 제한한 경우 원래 기준과 경고를 반환한다. 분류를 생략한 standard/normal 가정은 실제 분류와 구분한다. 실패·지연·할당량 소진으로 자동 대체하거나 승격하지 않는다. Luna/Sonnet 예외는 사소한 저위험 작업의 구체적 사유가 있을 때만 사용한다.

기준 원본은 [gon-skills model-router](https://github.com/krdn/gon-skills/tree/d0bb40cd31fb7ad0bc008b12bbc13dfa2197f3bf/skills/model-router)다. 기존 정확한 모델 ID는 수동 선택용으로 보존하고 별칭은 현재 등록으로 갱신한다. `gon-task-execute`와 `model-router`의 명시 호출 정책은 유지한다.

모델 정보는 2026-11-07 [OpenAI 공식 모델 안내](https://developers.openai.com/codex/models)와 [Anthropic 공식 모델 안내](https://platform.claude.com/docs/en/models/overview), 로컬 Codex 0.167.0의 지원 목록을 확인했다. 난이도별 표는 이 작업의 운영 결정이며 공식 벤치마크 결과가 아니다. 속도·비용 개선율은 아직 측정하지 않았다.

## 보존과 적용 범위

기존 개발 OS 작업 폴더의 미커밋 변경을 보존하고 최신 원격에서 별도 체크아웃했다. 기능 변경 전 라우터 기준본은 gon-skills `037a67f`, 개발 OS 기준본은 `8040016`으로 원격 확인했다. 원본 시험지·전사·인증값·전체 대화 로그는 이 보고서에 포함하지 않았다.

수정 대상은 개발 OS 실행 양식·매뉴얼과 canonical 스킬이다. 실행 중인 OCR 앱·사용자 자료는 변경하지 않는다. 새 기본값의 적용, 설치 파일 일치, 실제 모델 응답, 향후 과제에서의 성과는 각각 따로 확인한다.

최종 검사와 전달 상태는 [검증 결과](../evidence/field-upgrade-validation.json)에 기록한다.

관리 기록은 이번 두 저장소의 PR과 해당 SHA의 CI를 사용한다. 별도 Issue/Project 재구성과 Release·공개 배포는 이번 범위에 포함하지 않는다.
