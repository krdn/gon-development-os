# 저장소 통합 외부 리뷰

- 날짜: 2026-10-31
- 요청 모델·강도: `claude-opus-5-5`, `high`
- 실제 응답 `modelUsage`: `claude-opus-5-5`
- 실행: 정상 완료, 응답 오류 없음
- 범위: 신규 관리 문서, 매뉴얼·PDF·ZIP 생성기, 링크·스킬 검증, CI. 보존한 스킬 구현과 보관본 전체의 재리뷰는 아님.

## 지적과 처리

| 지적 | 반영 |
| --- | --- |
| PDF 제목의 첫 문자열 일치가 잘못된 북마크를 만들 가능성 | HTML의 장 ID에서 생성된 PDF named destination으로 정확한 페이지를 지정하고 제목·순서를 검사 |
| ZIP에 미추적·ignore 파일이 들어감 | Git 추적 파일과 지정 산출물만 포함, 심볼릭 링크 제외 |
| 오래된 PDF가 CI를 통과할 수 있음 | 빌드 전 원본·생성 결과와 커밋된 빌드 기록의 해시 일치 검사 |
| 스킬 하나만 업데이트하기 어려움 | 설치 목록에서 교체할 이름만 선택하는 절차 명시 |
| README 버전 고정 | VERSION 파일 링크로 변경 |
| skills 아래 일반 파일 때문에 검사 실패 | 디렉터리만 검사하고 스킬 수를 실제 값으로 출력 |
| 스킬 비교에 Python 캐시가 섞임 | 비교에서 __pycache__와 pyc 제외 |
| ZIP의 반복 커밋으로 이력 증가 | 새 빌드 ZIP은 Git에서 제외, 로컬·CI artifact로 제공 |
| PR에서 중복 CI 실행 | push는 main으로 제한 |

리뷰와 별도로 직접 PDF 링크를 점검해 페이지 복사만으로 named destination이 누락되는 문제를 재현했습니다. 전체 문서를 병합하면서 해당 대상을 보존하도록 고치고 내부 링크의 모든 목적지가 존재하는지 검사합니다.

수정분은 로컬 재생성·검사와 실패 조건 재현으로 확인합니다. 반복 외부 리뷰는 수행하지 않았습니다. PDF에서 외부 로컬 파일을 여는 상대 링크는 뷰어별 보안 정책의 영향을 받으며, 모든 PDF 뷰어에서 클릭 동작을 확인한 것은 아닙니다. 외부 자료를 열 때는 HTML 매뉴얼과 저장소 링크를 사용할 수 있습니다. 원격 CI 결과는 해당 커밋의 GitHub Actions 기록에서 확인합니다.
