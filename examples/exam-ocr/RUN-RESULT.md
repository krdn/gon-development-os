# Herdr 시험의 과거 결과와 재시험 조건

시험일: 2026년 11월 3일. 2026년 11월 6일 저장소 편입 시 로컬 인수 결과의 후속 기록까지 확인해 요약했다. 이 파일은 과거 결과이며 현재 앱 상태가 아니다.

| 단계 | 당시 확인한 결과 |
| --- | --- |
| 공간·주 모델 시작 | 별도 시험 공간에서 Codex 시작 및 요청 수신 |
| 문서 인수 | 프로젝트 문서를 실제로 읽고 입출력·제외 범위·AC10 미실행을 요약 |
| 요청 모델 | gpt-6-astra/xhigh, TUI 표시 확인. 서버 추론 메타데이터 미검증 |
| 도구 승인 | 작업 상태 기록 도구는 사용자 직접 승인 후 진행 |
| Herdr 제어 | 주 모델의 소켓 접근 Operation not permitted, core 조회 Read-only file system |
| 협업 | claude-fable-5-1/xhigh를 선택했으나 실제 실행·응답·파일 회수 NOT_RUN |
| 결과 저장 | 주 모델의 인수 결과 파일 저장·재읽기 성공 |
| 후속 기록 | 권한 요청이 불가한 세션 정책을 확인하고 공식 권한 경로를 안내. 접근 허용·협업 성공 증거는 결과 파일에 없음 |
| 제품 OCR/PDF | 구현·실제 변환·AC01~AC11 모두 NOT_RUN |

현재 저장소에는 [정제된 인수 결과](docs/ai/results/pilot-intake.md)를 보존한다. 개인 터미널 주소·전체 대화/화면·프로세스 정보는 재생성에 필요하지 않아 수록하지 않았다. 명령 승인 목록의 존재만으로 해당 명령의 성공·협업 응답을 주장하지 않는다.

재시험 때는 새로 실행한 주 모델의 도구 환경에서 `herdr-app ls`, `herdr-app status`, `herdr-core get` 접근부터 확인한다. 필요한 접근은 해당 CLI의 공식 권한 절차로 해결하며 설정을 임의로 확대하지 않는다. 현재 space/tab/terminal ID를 조회해 중복 작업자를 피하고, P002 결과 파일을 실제로 읽은 후에만 협업 성공을 기록한다.

이 문서 묶음으로 전체 제품 개발을 시작하려면 README의 시작 요청을 사용한다. 사용자 원본 시험지가 없으면 합성 개발·회귀검사만 진행할 수 있으며 AC10은 미실행으로 남는다.
