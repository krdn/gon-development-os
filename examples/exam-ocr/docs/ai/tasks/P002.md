# P002 독립 OCR 기술 질문

역할: 시험문제지 OCR PDF 설계의 기술 질문에 답하는 협업 모델. 이 질문의 답변은 사용자 승인이나 제품 구현 완료가 아니다.

- 요청 모델: claude-fable-5-1 / Claude Code / xhigh.
- 입력: docs/PROJECT-BRIEF.md, docs/ARCHITECTURE.md, docs/TEST-PLAN.md.
- 질문: 원본 보존 검색형 PDF와 문항 재조판 PDF는 어떻게 다른가? 수식·표가 있는 시험지에서 이 프로젝트가 반드시 확인할 세 가지 실패는 무엇인가? 실제 원본 없이 지금 할 수 있는 첫 개발 행동은 무엇인가?
- 출력: docs/ai/results/pilot-worker.md, 600자 안팎의 답변과 읽은 파일 경로.
- 허용 변경: 위 결과 파일 하나만.
- 금지: 제품 구현·의존성 설치·다른 문서 수정·새 작업자·전역 설정·외부 자료 업로드.
- 수용 기준: 위 세 질문에 답하고 AC10 미실행을 명시하며 실제 OCR을 돌렸다고 주장하지 않는다.
- 협업: 다른 작업자도 이 폴더를 사용한다. 다른 변경을 되돌리지 않는다.
- 회신: 부모가 전달한 terminal 주소가 있으면 herdr-core send로 결과 경로를 알린다. 주소가 없으면 결과 저장 후 최종 응답에 `HERDR_OCR_WORKER_DONE`과 경로를 쓴다.
