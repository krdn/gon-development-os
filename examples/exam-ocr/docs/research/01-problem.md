# 문제 정의

U01 사용자 요청: 시험문제지를 OCR 변환하여 PDF로 만드는 전체 프로젝트 문서를 기존 Herdr 서식에 채운다. 실제 Herdr에서 작동하는지 확인하는 용도다.

해결할 문제는 이미지로만 된 시험지의 문구 검색·복사와 순서 있는 PDF 보관이다. 교사·학생·학습자료 관리자를 예상 사용자로 삼되 실제 인터뷰나 수요 검증을 수행한 것은 아니다.

AI 기본안은 원본 배치를 유지한 검색형 PDF다. 문항을 다시 편집·조판하는 PDF는 별도 범위다. 원본 시험지, 과목, 페이지 수, 실제 품질은 미제공이므로 수용 검사 때 확인한다. 소스가 없어도 문서 인수 시험과 합성 기반 개발은 가능하다.
