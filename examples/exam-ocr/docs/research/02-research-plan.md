# 조사 계획

| 질문 | 확인 방법 | 결과 위치 |
| --- | --- | --- |
| 원본 배치를 유지하며 검색 PDF를 만들 수 있는가 | OCRmyPDF/Tesseract 공식 자료와 합성 페이지 실제 실행 | 03-evidence + D1 결과 |
| 한영 언어팩과 도구가 현재 설치됐는가 | 현재 PATH·버전·언어팩 조회 | 환경 기록 |
| 수식·표·복잡 배치의 위험은 무엇인가 | 공식 품질 안내와 S02 시각/텍스트 비교 | 품질 보고서 |
| Herdr에서 문서를 읽고 협업 결과를 받을 수 있는가 | PILOT의 실제 주 모델→협업→파일 회수 | evidence와 docs/ai/results |
| 실제 시험지에 충분한가 | 사용자 제공 원본과 정답 문구로 검사 | AC10 결과 |

시장 조사·상용 SaaS 비교·모델 전원 호출은 첫 범위에 필요하지 않다. 기술 문서는 공식 출처를 우선하고 실제 실행 증거와 분리한다.
