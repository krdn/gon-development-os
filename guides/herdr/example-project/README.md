# 문답에서 개발 시작 문서까지

이 폴더는 코드를 구현한 프로젝트가 아니라 **기획 문서 완성 모양**을 보여 주는 예시입니다. 자료를 읽으려면 설치가 필요하지 않습니다.

1. [P1 문제 정의](docs/research/01-problem.md): 질문과 답변이 어떻게 문제·제약이 되는지 봅니다.
2. [P2 조사 계획](docs/research/02-research-plan.md): 질문 Q번호와 필요한 증거를 정합니다.
3. [P3 근거표](docs/research/03-evidence.md): 실제 확인 여부와 미확인을 구분합니다.
4. [P4 결정 기록](docs/research/04-decision.md): 근거에서 선택 D번호가 나옵니다.
5. [P5 최종 문서](docs/PROJECT-BRIEF.md): 결정이 요구 R번호와 완료 기준 AC번호로 이어집니다.
6. [현재 상태](docs/STATE.md): 새 세션에 무엇을 읽힐지 적습니다.

각 문서는 단순한 대화 전문이 아닙니다. P1~P4 원본은 보존하고, 새 개발 세션은 최종 문서부터 읽습니다. 이 예시의 “합의”는 가상 사용자 답변에 대한 설명이며 사용자의 실제 승인을 대신하지 않습니다.
