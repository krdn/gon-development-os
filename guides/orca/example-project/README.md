# 문답이 개발 문서가 되는 실제 모양

이 폴더는 설명용 문서 묶음이며 실행할 앱 코드가 없다.

1. [P1](docs/research/01-problem.md): 질문과 답변 → 문제·제약.
2. [P2](docs/research/02-research-plan.md): 질문 Q번호 → 조사 방법.
3. [P3](docs/research/03-evidence.md): S/U 근거와 미확인 구분.
4. [P4](docs/research/04-decision.md): 근거 → 선택 D번호.
5. [최종 개발 문서](docs/PROJECT-BRIEF.md): D → R/AC.
6. [작업 계획](docs/TASKS.md): R/AC → 선행 관계·담당 파일·검증.
7. [현재 상태](docs/STATE.md): 다음 세션·GitHub·Orca 기록 위치.

폴더를 내 프로젝트에 그대로 승인본으로 복사하지 않는다. 빈 양식에서 실제 답변으로 작성한다.
