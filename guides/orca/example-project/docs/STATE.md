# 현재 상태 — Orca 인계 예시

- 프로젝트: 개인 할 일 앱 학습 예시
- 단계: P5 문서 예시. 실제 개발 승인·코드·시험·배포 없음.
- 읽을 순서: [PROJECT-BRIEF](PROJECT-BRIEF.md) → [TASKS](TASKS.md) → 이 파일.
- 현재 기획 세션: 개인할일-기획 (이름 예시). 실제 세션 ID: 없음.
- 다음 세션: 새 개발 주 조정자. 기획 채팅을 resume하지 않는다.
- 다음 행동: 실제 사용자 범위 확인 → 기술 선택 → Git 기준 저장 → K01.
- 미정: 기술, 저장 API 범위·유실 조건. 환경 구성·저장 구현 전에 해결.
- GitHub 저장소·이슈·PR: 아직 없음.
- 기준 브랜치·커밋: 아직 없음.
- Run / Task / Dispatch: 아직 실행하지 않음.
- 활성 작업자: 없음. 종료했다는 뜻이 아니라 아직 시작하지 않은 예시다.
- 담당: 주 조정자는 통합 문서, 조사 작업자는 지정 notes 파일만 작성.

재개 시: 문서가 현재 상태와 맞는지 실제 Git·파일·Orca 상태부터 확인한다.
Orca Run은 작업 묶음이며 Codex의 대화 세션과 같은 ID가 아니다.

GitHub 연결 후 작업 상태의 기준은 Issues/기존 Projects이며, 이 파일은 실제 URL과 Orca 작업의 대응 요약으로 유지한다. 연결되지 않았다면 pending_sync 또는 아직 없음으로 구분한다.
