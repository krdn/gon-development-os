# P1 문제 정의

상태: 설명용 문답 정리 / 기술은 아직 미정

| 질문 | 가상 사용자 답변 | 구분 |
| --- | --- | --- |
| 누구를 위한 앱인가? | 내 학습용이다. 판매하려는 것은 아니다. | 사용자 목적 U01 |
| 어떤 상황이 불편한가? | 연습할 일을 적어도 새로고침하면 사라지는 연습 앱은 불편하다. | 가상 경험 U02 |
| 어디에서 쓸 것인가? | 같은 PC의 같은 브라우저에서 쓴다. | 제약 U03 |
| 로그인·동기화가 필요한가? | 첫 버전에서는 필요 없다. | 제외 결정 후보 |
| 저장 데이터가 사라지면 안 되는가? | 연습용이라 가능하지만, 저장 한계는 알고 싶다. | 조사 질문 |

문제 한 문장: 개인 학습을 위해 할 일을 추가·완료·삭제하고 같은 브라우저의 새로고침 후에도 남는 작은 앱을 만든다.

확정: 학습용, 개인용, 같은 브라우저. 가정: 이 기능 구성이 학습에 도움이 될 것. 미정: 저장 방식·구현 기술·브라우저 데이터 삭제 시 동작.
