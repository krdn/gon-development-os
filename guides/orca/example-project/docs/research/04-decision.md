# P4 결정 기록

상태: 설명용 가상 합의

| 결정 | 선택 | 이유·근거 | 제외·미정 |
| --- | --- | --- | --- |
| D01 | 학습용 앱을 직접 만든다 | U01: 개발 학습이 목적 | 상용 수요를 확인했다는 주장은 하지 않음 |
| D02 | 추가·완료/해제·삭제·새로고침 유지 | U02·U03: 작은 전체 흐름을 익힘 | 로그인·동기화·서버·알림 제외 |
| D03 | 기술·저장 API는 개발 준비에서 비교·확인 | S01이 아직 미확인 | D1 개발 준비에서 결정, 저장 구현 전에 해소 |

대안: 당장 편한 도구만 필요하다면 기존 도구 사용으로 종료할 수 있다. 학습 목표가 없어지거나 요구가 여러 기기 동기화로 바뀌면 이 결정을 재검토한다.

실제 검증: 이 문서 묶음은 설명용이며 사용자 인터뷰나 앱 테스트를 수행하지 않았다.
