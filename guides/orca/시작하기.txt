Orca + Codex CLI 실행 안내서

1. ZIP을 풀고 index.html을 브라우저로 여세요.
2. 프로젝트명과 실제 폴더를 입력하고 “요청문에 반영”을 누르세요.
3. 전체 흐름의 S0를 누르고 열 창·순서·요청문·확인을 따라가세요.
4. guide.pdf는 기본값으로 만든 인쇄본입니다. 내 값으로 바꾼 뒤 HTML에서 인쇄/PDF를 쓰면 맞춤본을 만들 수 있습니다.
5. examples.html에는 P1~P5의 전체 문서 예시가, templates/에는 빈 양식이 있습니다.

기존 기획 세션은 P1~P5와 Git 기준 저장까지 유지합니다.
활성 작업자를 정리한 뒤 새 개발 세션에서 최종 문서를 읽어 시작합니다.
작업자가 진행 중일 때는 주 조정자 탭을 유지합니다.

예시는 설명용이며 실제 사용자 조사·승인·프로젝트 실행 결과가 아닙니다.
안내서의 화면·복사·PDF·링크를 검증했습니다. 외부 리뷰는 응답 없이 종료되어 미완료입니다.
