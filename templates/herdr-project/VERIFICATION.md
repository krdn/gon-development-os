# 실행 양식의 검증 범위

이 양식은 Herdr에서 주 모델이 읽고 수행하는 문서 계약이다. 파일 자체가 상주 실행기나 자동 복구 서비스는 아니다.

2026년 11월 3일 작성 시 설치된 Herdr app 0.1.12/core 0.1.17 도움말과 명령 구조를 대조했다. 현재 기기의 버전·모델 목록·권한·terminal/pane ID는 실행 시 다시 확인한다. 주 모델 내부에서 앱/core 접근과 첫 요청 수신을 확인해야 하며, 외부 쉘에서의 성공만으로 추정하지 않는다.

별도 OCR 예시의 과거 시험은 문서 읽기와 결과 저장까지 성공했지만 협업 실행이 접근 권한으로 차단됐다. 이 양식을 사용하면 모든 프로젝트가 자동 완료된다는 검증은 하지 않았다. 모델 응답·결과 저장·통합·제품 동작·배포를 각각 확인한다.

현재 저장소의 빌드는 문서 링크와 파일 무결성을 검사한다. 서버가 적용한 실제 모델·effort, 사용자 데이터의 OCR 정확도, 운영 배포는 별도 검증 대상이다. 지원되는 공식 권한 절차를 따르며 샌드박스 제한을 우회하지 않는다.

## 1.4.1 스킬 통합 검토

[Opus 검토와 지적 처리 기록](../../evidence/herdr-skill-integration-review.json)에 단계별 스킬 선택, P5 인수 회신, 작업자 역할·결과 기록, 미설치와 구버전 문서 재개의 검토 범위를 남겼다. 전문 스킬의 원본과 호출 정책은 `skills.lock`의 버전을 따른다.

두 실행 문서를 읽은 주 모델이 단계별 규칙을 수행하도록 문서로 연결했다. 실제 세션에서의 지침 읽기·적용은 STATE나 작업 결과의 경로·참조·작업 근거로 확인한다. 이번 문서 재생성과 정적 리뷰로 여러 세션의 인계나 실제 웹 구현을 실행 검증했다고 판정하지 않는다.
